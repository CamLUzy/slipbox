# 卡片盒 · 卢曼卡片笔记（Mac 本地应用）

一个按 Niklas Luhmann 卡片盒方法（Zettelkasten）设计的 Mac 应用。所有数据只保存在这台 Mac 上，不联网、不需要账号。

- **应用**：`卡片盒.app`，原生 macOS 窗口和菜单栏，支持 Apple 芯片和 Intel，macOS 12 及以上。
- **多个卡片盒**：每个卡片盒是一个独立的 SQLite 文件，适合按课程或项目分开。点左上角的卡片盒名字（或 ⌘O）可以新建、切换、重命名和删除（删除会移到废纸篓）。
- **数据**：`~/Library/Application Support/卡片盒/boxes/<卡片盒名>.db`。
- **备份**：每个卡片盒每天自动备份到 `backups/<卡片盒名>/`，保留最近 30 份。

## 安装 / 构建

只需要 Xcode 命令行工具（`xcode-select --install`），不需要完整的 Xcode：

```
bash mac/build.sh             # 生成 dist/卡片盒.app
bash mac/build.sh --install   # 生成并安装到 /Applications
```

想卸载的话，把 `/Applications/卡片盒.app` 拖进废纸篓即可。数据文件夹不会被删除，如需彻底清除，再手动删掉 `~/Library/Application Support/卡片盒`。

## 卢曼方法在这里怎么用

| 卢曼的做法 | 在本应用里 |
|---|---|
| **闪念笔记** | 左上角 ＋、按 `N` 或 `⌘N`，进入“收件箱”。 |
| **文献卡片**（书目卡片盒） | “文献”页或 `⌥⌘N` 新建，填写文献键（如 `Luhmann1992`）、作者、年份，正文用自己的话写摘要。 |
| **永久卡片** | 收件箱里的笔记点“整理进卡片盒”，改写成只讲一个观点的卡片，并选择位置。 |
| **固定编号 Folgezettel** | 新主题 `1`、`2`…；**续写**接在后面（`1` → `2`，若已被占用则 → `1a`）；**分支**从中间岔开（`1a` → `1a1`、`1a2`）。数字与字母交替，可以无限插入。 |
| **卡片间链接** | 正文写 `[[1a2]]`，或 `[[1a2|显示文字]]`；`[[@Luhmann1992]]` 引用文献。输入 `[[` 会自动补全。 |
| **关键词索引** | 给少数“入口”卡片加关键词，它们出现在“索引”页。 |
| **翻阅卡片盒** | 卡片页底部的 ‹ › 按编号顺序翻到上一张/下一张（`K` / `J`）。 |
| **与卡片盒对话** | “随机漫步”（`R` / `⌘R`）、“关系图”（`G`）；首页列出“缺少入口的主题”。 |

编号原则上不变。确实需要调整时，卡片页的“改号”会把这张卡片连同它的全部分支一起移动，并自动更新所有指向它们的链接。

**快捷键**：`A` 或 `⌘J` AI 助手 · `N` 闪念 · `/` 或 `⌘F` 搜索 · `E` 编辑 · `C` 续写 · `B` 分支 · `J`/`K` 下一张/上一张 · `G` 关系图 · `R` 随机 · `⌘S` 保存 · `Esc` 取消 · `⌘+`/`⌘-` 缩放

## AI 功能（本地模型，可选）

AI 通过本机的 [Ollama](https://ollama.com) 运行，默认模型是 `qwen3.5:4b`（约 3.3 GB）。卡片内容不会离开这台 Mac：应用只允许连接本机上的 Ollama。

**只在点击时启动**：平时模型不占内存，点任何一个 AI 按钮才会加载（几秒）。闲置 5 分钟后 Ollama 会自动释放内存，这个时间可以在 AI 助手页改成 1 或 30 分钟；也可以随时点“释放内存”，或用菜单“AI → 释放模型内存”。如果 Ollama 没在运行，应用会自动在后台打开它。

| 功能 | 在哪里 | 做什么 |
|---|---|---|
| **AI 整理** | 闪念或卡片页的“✦ AI 整理” | 把笔记改写成合格的永久卡片：一句话标题、精炼正文、关键词，建议放在卡片盒的哪个位置（续写/分支），以及应该链接哪些卡片。点“用这个结果编辑”会填进编辑器，由你确认后保存。 |
| **AI 梳理联系** | 卡片页的“✦ 梳理联系” | 找出内容相近的卡片，判断它们和这张卡片的关系（支持、反驳、举例、延伸、前提、对比、相似），画成关系图（实线表示已有链接，虚线表示 AI 建议）。点“加入链接”会在卡片末尾写入一行 `- 类型：[[编号]] 理由`。 |
| **梳理整个卡片盒** | AI 助手（⌘J）→ 梳理整个卡片盒 | 给每个主题序列命名并概括，找出相关却没链接的卡片对，在一张总图里按主题上色，可拖动、缩放。 |
| **AI 助手对话** | AI 助手（⌘J），或卡片页“就这张卡片提问” | 先从卡片盒里找出相关卡片，再根据它们回答，回答中的 [[编号]] 可以直接点开；“存为闪念”可以把好的回答放进收件箱。 |

找相关卡片这一步用的是本地文本相似度（中文二元组 + TF-IDF），不需要另外的模型，只有判断关系、写作和回答需要大模型。

4B 小模型的判断不一定可靠（例如会把“支持”判成“反驳”），所以所有 AI 结果都只是建议，必须由你确认后才会写进卡片。想换模型，可以在“设置与数据 → AI”里改模型名，再 `ollama pull <模型名>`。

## 数据

- “设置与数据”（`⌘,`）里可以在 Finder 中显示数据文件、立即备份、导出 JSON、导出为 Markdown 文件夹（每张卡片一个 `.md`，带 front matter，可用 Obsidian 等打开）、从 JSON 导入。
- 从备份恢复：退出应用，用 `backups/<卡片盒名>/` 里的某个 `zettel-日期.db` 替换 `boxes/<卡片盒名>.db`（同时删掉旁边的 `-wal`、`-shm` 文件）。
- 换电脑：复制整个 `~/Library/Application Support/卡片盒` 文件夹，或导出 JSON 后在新电脑上导入。

## 浏览器版（备用）

同一套界面也能在浏览器里运行，这时数据保存在浏览器的 IndexedDB 里：

```
npm run dev      # 然后打开 http://localhost:8790
```

浏览器版主要用于开发调试。数据只存在那个浏览器里，清除浏览器数据会一起删掉，请定期导出 JSON。

## 文件结构

```
zettelkasten/
├─ mac/
│  ├─ main.swift     原生外壳：窗口、菜单栏、SQLite 存储、自动备份、存储/打开面板、本机 Ollama 代理
│  ├─ Info.plist, AppIcon.png
│  └─ build.sh       构建脚本
├─ web/              界面（HTML / CSS / 原生 JavaScript，无需构建）
│  └─ js/
│     ├─ luhmann.js  Folgezettel 编号规则
│     ├─ ops.js      新建、修改、删除、恢复、改号、导入（纯函数）
│     ├─ store.js    内存中的卡片与索引（树、反向链接、关键词）
│     ├─ backend.js  存储：应用内走 SQLite，浏览器里走 IndexedDB
│     ├─ app.js      界面
│     ├─ ai.js       Ollama 调用与提示词（整理 / 关系 / 主题 / 对话）
│     ├─ aiview.js   AI 界面（整理面板、关系图、总图、对话）
│     ├─ similarity.js 本地文本相似度（找候选卡片）
│     ├─ markdown.js Markdown 渲染与 [[链接]]
│     └─ graph.js    关系图
└─ tests/
   ├─ core.test.js       单元测试（npm test）
   ├─ app-selftest.js    在真实应用里运行的自测脚本
   └─ app-ai-selftest.js AI 功能自测（会加载模型约一分钟）
```

运行应用自测（`ZK_DATA_DIR` 指向临时数据目录，不会碰到你的数据，也不会改变应用记住的当前卡片盒）：

```
ZK_DATA_DIR=/tmp/zk-test ZK_SELFTEST=$PWD/tests/app-selftest.js "dist/卡片盒.app/Contents/MacOS/Zettelkasten"
```

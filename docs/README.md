## 卢曼方法在卡片盒里怎么用

| 卢曼的做法 | 在卡片盒里 |
|---|---|
| **闪念笔记** | 左上角 ＋、按 `N` 或 `Ctrl/⌘ + N`，进入“收件箱”。 |
| **文献卡片**（书目卡片盒） | “文献”页新建，填写文献键（如 `Luhmann1981`）、作者、年份，正文用自己的话写摘要。 |
| **永久卡片** | 收件箱里的笔记点“整理进卡片盒”，改写成只讲一个观点的卡片，并选择位置。 |
| **固定编号 Folgezettel** | 新主题 `1`、`2`…；**续写**接在后面（`1` → `2`，若已被占用则 → `1a`）；**分支**从中间岔开（`1a` → `1a1`、`1a2`）。数字与字母交替，可以无限插入。 |
| **卡片间链接** | 正文写 `[[1a2]]` 或 `[[1a2\|显示文字]]`；`[[@Luhmann1981]]` 引用文献。输入 `[[` 会自动补全。 |
| **关键词索引** | 给少数“入口”卡片加关键词，它们出现在“索引”页。 |
| **翻阅卡片盒** | 卡片页底部的 ‹ › 按编号顺序翻到上一张/下一张（`K` / `J`）。 |
| **与卡片盒对话** | 随机漫步（`R`）、关系图（`G`）、AI 助手；首页列出“缺少入口的主题”。 |

编号原则上不变。确实需要调整时，卡片页的“改号”会把这张卡片连同它的全部分支一起移动，并自动更新所有指向它们的链接。

## 快捷键

Windows 用 `Ctrl`，macOS 用 `⌘`。

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `N` | 记录闪念 | `/` 或 `Ctrl/⌘ F` | 搜索 |
| `E` | 编辑当前卡片 | `Ctrl/⌘ S` | 保存 |
| `C` | 续写 | `B` | 分支 |
| `J` / `K` | 下一张 / 上一张 | `G` | 关系图 |
| `R` | 随机漫步 | `A` 或 `Ctrl/⌘ J` | AI 助手 |
| `Ctrl/⌘ O` | 切换卡片盒 | `Esc` | 取消编辑 |

## 第一次用

1. 打开 **设置与数据 → 从 JSON 导入**，选 [`demo/demo-box.json`](demo/demo-box.json)，先看看一个现成的卡片盒长什么样。
2. 点左上角卡片盒名字，**新建** 一个自己的卡片盒（比如按课程命名）。
3. 读到想法时随手按 `N` 记闪念，每天花几分钟在收件箱里把它们整理成永久卡片。

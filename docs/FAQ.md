# FAQ

**卡片会上传到哪里吗？**
不会。卡片只保存在本机的 SQLite 文件里，应用不联网；AI 只连本机的 Ollama。

**编号能改吗？会不会弄乱链接？**
可以，用卡片页的“改号”。整串分支会一起移动，所有指向它们的 `[[链接]]` 都会自动改成新编号。

**删除的卡片去哪了？**
先进回收站，可以恢复；在回收站里“永久删除”才会真正删掉。删除整个卡片盒时，文件会移到系统的废纸篓 / 回收站。

**能在两台设备之间同步吗？**
目前还没有自动同步，可以拷贝 `boxes/<名字>.db`（三个平台格式相同）或导出导入 JSON。局域网一键同步的方案见 [多端互联](SYNC.md)，计划在 v1.2 实现。

**iPhone 版怎么装？**
没有上架 App Store，用 Sideloadly / AltStore 安装 Release 里的 `.ipa`，或用 Xcode 从源码装，见 [iPhone / iPad](IOS.md)。

**Windows 上提示“Windows 已保护你的电脑”？**
安装包没有代码签名证书，点“更多信息 → 仍要运行”。见 [Windows](WINDOWS.md)。

**便携版打不开、窗口一片空白？**
电脑缺 WebView2 运行时，改用安装版，或从微软官网安装 WebView2。

**AI 按钮点了没反应 / 提示连接不到 Ollama？**
确认装了 Ollama；应用会尝试自动启动它。模型没下载时界面会提示下载。见 [本地 AI](AI.md)。

**AI 的建议靠谱吗？**
4B 小模型适合找线索，不适合做最终判断。所以所有结果都只是建议，由你决定要不要写进卡片。

**为什么界面是中文？**
作者用中文写卡片。英文界面在路线图里，欢迎贡献。

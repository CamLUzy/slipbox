# FAQ

**卡片会上传到哪里吗？**
不会。卡片只保存在本机的 SQLite 文件里；AI 只连本机（iPhone 上是局域网里）的 Ollama，或用设备上的 Apple 端侧模型；同步只在你自己的两台设备之间直连。应用联网只有一种情况：你点了“一键安装 Ollama”，它会从 Ollama 官方的 GitHub 下载安装包。

**编号能改吗？会不会弄乱链接？**
可以，用卡片页的“改号”。整串分支会一起移动，所有指向它们的 `[[链接]]` 都会自动改成新编号。

**删除的卡片去哪了？**
先进回收站，可以恢复；在回收站里“永久删除”才会真正删掉。删除整个卡片盒时，文件会移到系统的废纸篓 / 回收站。

**能在两台设备之间同步吗？**
可以。两台设备连同一个 Wi-Fi、都打开 **设备与同步**，在其中一台点“同步”。第一次要在两台设备上核对一组 6 位数字完成配对。见 [多端互联](SYNC.md)。

**同步时找不到另一台设备？**
先确认两台都开着“设备与同步”页面、在同一个 Wi-Fi 下（访客网络、公司网络常常禁止设备互相发现）。macOS 和 iPhone 要允许“本地网络”权限，Windows 要在防火墙提示里允许“专用网络”。还不行就展开“找不到？”，输入对方页面上显示的地址（例如 `192.168.1.20:51515`）。

**两台设备都改了同一张卡片会怎样？**
保留较新的一份；较旧的一份作为“【冲突副本】”闪念放进收件箱，内容不会丢。同步前两边都会自动备份。

**把整个数据文件夹拷到了另一台设备上，同步找不到对方？**
文件夹里的 `sync.json` 是这台设备的身份，拷过去以后两台设备的身份就一样了。在新设备上退出卡片盒，删掉 `sync.json` 再打开即可（会生成新的身份，需要重新配对）。

**iPhone 版怎么装？**
没有上架 App Store，用 Sideloadly / AltStore 安装 Release 里的 `.ipa`，或用 Xcode 从源码装，见 [iPhone / iPad](IOS.md)。

**Windows 上提示“Windows 已保护你的电脑”？**
安装包没有代码签名证书，点“更多信息 → 仍要运行”。见 [Windows](WINDOWS.md)。

**便携版打不开、窗口一片空白？**
电脑缺 WebView2 运行时，改用安装版，或从微软官网安装 WebView2。

**AI 按钮点了没反应 / 提示没有安装 Ollama？**
点“一键安装 Ollama 和模型”，应用会下载安装并显示进度；Mac 上也可以改用系统自带的 Apple 端侧模型（macOS 26 并打开 Apple 智能）。已经装了 Ollama 的话，应用会自动启动它。见 [本地 AI](AI.md)。

**AI 的建议靠谱吗？**
4B 小模型适合找线索，不适合做最终判断。所以所有结果都只是建议，由你决定要不要写进卡片。

**为什么界面是中文？**
作者用中文写卡片。英文界面在路线图里，欢迎贡献。
